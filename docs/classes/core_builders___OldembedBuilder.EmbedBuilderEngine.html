    Class EmbedBuilderEngine

    EmbedEngine

    Class-based engine with a persistent global BuildContext and configurable default BuildOptions. Local context / options passed to build() are merged on top (local values take precedence).

    Adds buildChunks() for unlimited embed sets (Code 4 exclusive feature).

    Example

    export const engine = new EmbedBuilderEngine(
      { attachments: { "logo.png": { name: "logo.png", data: logoBuffer } } },
      { strict: false },
    );

    // In a command handler:
    const result = engine.build(layout);

    // Or paginate 50 embeds automatically:
    const pages = engine.buildChunks(bigLayout);  // → EmbedBuildResult[]
    for (const page of pages) await channel.send(page);

      buildChunks (Code 4 exclusive feature)

      Splits an unlimited number of EmbedSpecs into an array of valid message payloads, each containing at most 10 embeds.

      Ideal for:

      • Paginated log dumps
      • Dynamic embed lists of unknown length
      • Bulk notification systems

      Parameters

      • layout: EmbedLayout
      • OptionallocalContext: BuildContext
      • OptionallocalOptions: BuildOptions

      Returns EmbedBuildResult[]

      Example

      const pages = engine.buildChunks({ embeds: [...50 embed specs...] });
      for (const page of pages) await channel.send(page);
